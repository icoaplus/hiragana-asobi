# ひらがなあそび

8種類のひらがな学習ゲームを収録したWebアプリです。

## GitHub Pagesへの公開

1. このZIPを展開し、**中のファイルとフォルダーをすべて**リポジトリのルートに配置します。
2. リポジトリ名は `hiragana-asobi` を推奨します。
3. GitHub の Settings → Pages → Build and deployment で `Deploy from a branch` を選び、`main` / `/(root)` を指定します。
4. 公開URL例：`https://icoaplus.github.io/hiragana-asobi/`

※ZIPファイルをそのままGitHubにアップロードしてもWebアプリとして動きません。必ず展開してください。
※画像・音声など1,000個以上のファイルがあります。GitHub DesktopまたはGitを使って登録するとスムーズです。
※これはコンテスト応募用の保存版です。今後のiPad向け調整はコピーまたは別バージョンで進めてください。
